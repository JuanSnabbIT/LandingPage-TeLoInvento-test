# IoT Enclosure V1 — Fuente de verdad

Este paquete contiene la especificación mecánica y el procedimiento de trabajo para diseñar la carcasa V1 del dispositivo IoT.

## Estado del hardware

La PCB física actual se considera **definitiva para esta versión**.

## Regla principal

No inventar dimensiones físicas. Los datos se clasifican como:

- `MEDIDO_APROX`: medida tomada del hardware, suficiente para blockout/prototipo.
- `DERIVADO`: calculado a partir de medidas.
- `APROBADO`: decisión de diseño aceptada.
- `INICIAL`: valor de diseño que se validará en Blender o impresión.
- `PENDIENTE`: dato aún no definido.
